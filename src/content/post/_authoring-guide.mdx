## Headings & table of contents

Use `##` (h2) and `###` (h3). The TOC in the sidebar (desktop) and the
"On this page" box (mobile) build themselves from these automatically —
it appears once a post has 2+ headings.

## Citations and notes

Sources come from the shared BibTeX file `src/content/references.bib`
(export from Zotero/JabRef; keep `@` out of its comment lines). Cite with
the key; only cited entries are listed, IEEE style, under "References":

```md
No unitary can copy an unknown state [@wootters1982].
Several at once: [@nielsen2010; @epr1935]
```

Hovering a `[1]` shows the entry; DOIs become links. Footnotes (`[^key]`)
are for side remarks and are listed under "Notes".

## Callouts

No import needed — these are available in every post:

<Callout type="note">
  Default note. Markdown works inside: **bold**, `code`, [links](/).
</Callout>

<Callout type="tip" title="Pro tip">
  Custom titles via the `title` prop.
</Callout>

<Callout type="warning">
  Amber, for things that can go wrong.
</Callout>

<Callout type="important">
  Violet, for the one thing readers must not miss.
</Callout>

## Quotes

For short inline quotes, plain markdown `>` blockquotes are fine. For a
featured quote with attribution:

<Quote author="Richard Feynman" source="Simulating Physics with Computers" href="https://doi.org/10.1007/BF02650179">
  Nature isn't classical, dammit, and if you want to make a simulation of
  nature, you'd better make it quantum mechanical.
</Quote>

`author`, `source` and `href` are all optional.

## Math

Inline: $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ — display:

$$
\hat{H}\,|\psi\rangle = i\hbar \frac{\partial}{\partial t}|\psi\rangle
$$

Rendered at build time (KaTeX). `aligned`, `pmatrix` etc. all work.

## Code

Fenced blocks get syntax highlighting and a copy button automatically:

```python
def hadamard(qubit):
    return H @ qubit  # superposition
```

## Abstract

Optional frontmatter, shown in a box above the post and in structured data:

```yaml
abstract: We show that no unitary can clone an unknown quantum state.
```

## Cover image

Posts without an `image` get generated covers: a titled one for link
previews and a text-free one for blog cards, whose motif follows the
category (or tags), in English or Turkish: quantum computing → Bloch sphere,
quantum optimisation → energy landscape, quantum information → circuit,
optics → waves, physics → orbits, maths → plot, computer science → tree,
ML → neural network, electronics → oscilloscope, sociology → network of
communities, history → timeline, philosophy → ripples, anything else →
constellation. Override with e.g. `cover: network` in the frontmatter.

## Figures, charts and animations

All are numbered "Figure N" in order; the text inside is the caption
(markdown and math work). `alt` describes the content for screen readers.

```mdx
import loss from '~/assets/images/posts/my-post/loss.svg';

<Figure src={loss} alt="Loss falling from 2.3 to 0.4" id="fig:loss">
  Training loss per epoch.
</Figure>

<PlotlyChart src="/figures/my-post/bloch.json" alt="…" id="fig:bloch" height={480}>
  Interactive Bloch sphere.
</PlotlyChart>

<Animation src="/videos/my-post/h.mp4" poster="/videos/my-post/h.png" alt="…" id="fig:h" autoplay>
  The Hadamard gate as a rotation.
</Animation>
```

- **matplotlib:** `plt.style.use("tools/furkaneyazici.mplstyle")`, then
  `fig.savefig("src/assets/images/posts/<post>/<name>.svg")`: transparent,
  site colours, vector.
- **Plotly:** `fig.write_json("public/figures/<post>/<name>.json")`. The
  site theme replaces the notebook's; Plotly loads only when the chart is
  near the screen. LaTeX inside Plotly labels isn't rendered.
- **Manim:** copy `tools/manim.cfg` next to the scene (site background
  colour), render with `manim -qh scene.py Name` (and `-s` for the poster
  frame), put both in `public/videos/<post>/`. `autoplay` plays muted and
  looped while visible, never with reduced motion.
- YouTube/CodePen embeds are blocked by the CSP in `netlify.toml`; ask
  before adding one.

## Equations, theorems and references

Only labelled equations are numbered. `<Ref>` prints the number and links
to it; an unknown label stops the build.

```mdx
$$
i\hbar\,\partial_t|\psi\rangle = \hat H|\psi\rangle \label{eq:schrodinger}
$$

<Definition title="Qubit" id="def:qubit">A unit vector in $\mathbb{C}^2$.</Definition>

<Theorem title="No-cloning" id="thm:no-cloning">No unitary copies every state.</Theorem>

<Proof>Linearity contradicts copying two non-orthogonal states.</Proof>

By <Ref to="thm:no-cloning" /> and <Ref to="eq:schrodinger" /> … (also <Lemma>)
```

`<Proof>` is collapsed by default and ends with ∎.

## From a Jupyter notebook

```sh
python scripts/notebook-to-post.py path/to/notebook.ipynb --slug my-post
```

Creates a draft post: markdown cells (made MDX-safe), code, outputs (SVG/PNG
→ `<Figure>`, Plotly → `<PlotlyChart>`, text). Cell tags `remove-cell`,
`remove-input`, `remove-output`, `hide-input` are honoured. Then fill in
the TODO alt texts, captions and excerpt, and set `draft: false`.

## Translations

To publish a post in more than one language, create one file per language
and give them the **same `translationKey`**. Each version gets its own
filename (= its own URL) and its own `lang`:

```yaml
# quantum-errors.mdx            # quantum-errors-tr.mdx
title: Quantum error correction   title: Kuantum hata düzeltme
translationKey: quantum-errors    translationKey: quantum-errors
                                  lang: tr
```

`lang` defaults to `en`, so English posts only need the key. Linked
versions automatically get:

- an "Also available in: Türkçe / English / …" switcher above the title
- `hreflang` alternate tags in the head (search engines serve the right one)
- a language badge on blog cards for non-English posts
- correct `lang` attributes for screen readers and hyphenation

Any BCP-47 code works (`tr`, `de`, `fr`, `ja`…) — the switcher shows each
language's native name automatically.
